# Song Handler

A music discovery web app built with React and Vite. Search for albums and artists, explore featured music, save favorites, and manage your profile with Supabase authentication.

## Live Demo

https://song-handler.vercel.app/

## Features

- Search albums using the iTunes Search API
- Artist search suggestions
- Today's Special and Trending music sections
- Save and remove favorite albums
- User-specific favorites
- Email/password authentication
- Google and GitHub authentication
- User profile with editable information
- Responsive design for desktop and mobile
- Direct links to albums on Apple Music/iTunes

## Tech Stack

- React
- Vite
- Tailwind CSS
- Supabase Authentication
- iTunes Search API
- JavaScript
