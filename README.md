# 🎵 Song Handler

A responsive music discovery web application built with React and Vite. Song Handler allows users to search for artists and albums, explore trending music, save their favorite albums, and manage their profile.

## 🌐 Live Demo

[🎵 Open Song Handler](https://song-handler.vercel.app/)

## ✨ Features

- 🔎 Search for artists and albums
- 💡 Artist search suggestions
- 🎵 Today's Special section
- 🔥 Trending music section
- ↔️ Horizontal music carousels
- ❤️ Add and remove favorite albums
- 👤 User-specific favorites
- 🔐 Email and password authentication
- 🔵 Google authentication
- ⚫ GitHub authentication
- 👤 Editable user profile
- 📱 Responsive design for desktop, tablet, and mobile
- 🎧 Direct links to albums on Apple Music/iTunes

## 🔐 Authentication

Song Handler uses Supabase Authentication with:

- Email & Password
- Google OAuth
- GitHub OAuth

Each logged-in user has their own favorites and profile information.

## 🔌 API Integration

Song Handler uses the iTunes Search API to retrieve music data such as:

- Artist information
- Album information
- Album artwork
- Release year
- Apple Music/iTunes album links

## 📱 Responsive Design

The application is designed to work across different screen sizes, including:

- Desktop
- Tablet
- Mobile

Music sections use horizontal scrolling carousels, with an expanded multi-row view available through the "See all" option.
